# Security Policy

This repository is maintained on a best-effort basis.

If you believe you found a security issue, please avoid opening a public issue first. Use GitHub private vulnerability reporting if it is available, or contact the maintainer through a non-public channel.

Please include:

- a short description of the issue
- affected commit, tag, or branch
- reproduction steps or a minimal proof of concept
- expected impact

I may not be able to provide strict response timelines, but I will review reports when possible and prefer coordinated disclosure until there is a fix, mitigation, or a clear decision to disclose.
